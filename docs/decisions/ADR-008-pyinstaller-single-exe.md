# ADR-008: Distribute as a Single PyInstaller Exe

**Status:** Accepted  
**Date:** 2026-05-17  
**Affects:** [F-010](../features/F-010-versioned-build.md)

---

## Context

ScRecorder targets end users who may not have Python installed. A distribution format is needed that works on Windows 7–11 without requiring a Python installer or virtual environment setup. Options:

- **PyInstaller `--onefile`** — single exe, all assets bundled
- **PyInstaller `--onedir`** — folder with exe + DLLs + assets
- **NSIS / Inno Setup installer** — traditional Windows installer
- **Portable folder (zip)** — distribute folder without installer

## Decision

Use PyInstaller `--onefile` (single exe) with ffmpeg.exe bundled as a binary (`assets/ffmpeg.exe`). The spec file is generated by `build.py` with Windows PE metadata via `version_info.txt`.

See `build.py` — `make_spec()`, `make_version_info()`.

## Rationale

- **Zero-install for users:** Double-click the exe — no Python, no pip, no DLL extraction required by the user
- **Single file to distribute:** One file on GitHub Releases, no zip extraction
- **PE metadata:** Windows file Properties → Details shows version, product name, and copyright when `version_info.txt` is embedded — gives the exe a professional appearance
- **Portable:** Exe can be placed anywhere; config is in `%APPDATA%`, not next to the exe

## Consequences

**Positive:**
- Simplest possible distribution story for users
- Version visible in Windows file properties
- No installer infrastructure needed

**Negative:**
- **Large output exe** (~245MB) because ffmpeg.exe (~200MB) is bundled — users download a large file even for small updates
- **AV false positives:** PyInstaller executables trigger heuristic detection in some AV software (Defender, Bitdefender) — particularly unsigned ones. Users may need to add an exception.
- **Slow cold start:** `--onefile` extracts to `%TEMP%\...` on first run — startup is slower than `--onedir` for large bundles
- **No code signing:** Without an Authenticode certificate, Windows SmartScreen shows an "Unknown publisher" warning on first run

## Alternatives Considered

- **PyInstaller `--onedir`:** Faster startup (no extraction), smaller incremental updates possible. Rejected because distributing a folder (zip) is worse UX than a single exe.
- **NSIS installer:** Professional installation experience, Start Menu shortcut, proper uninstall. Adds build toolchain complexity. Overkill for current scope; consider for v2.0.
- **Nuitka:** Compiles Python to C, produces a native exe with better AV compatibility and startup speed. More complex build process. Worth evaluating if AV false positives become a significant user issue.

## Future Considerations

- Code signing via an Authenticode certificate eliminates SmartScreen warnings and dramatically reduces AV false positives. Consider for any public commercial release.
- `--onedir` + zip may be preferable if the exe size exceeds 300MB or if delta updates become needed.
